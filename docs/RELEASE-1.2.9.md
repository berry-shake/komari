# 1.2.9 移除 MJPEG 图片流

- 删除 `/api/mjpeg_live` 路由及全部图片流渲染代码，包括定时生成 JPEG、共享字体对象和 MiSans 字体自动下载。
- 清理仅供图片流使用的 `golang.org/x/image` 依赖。该渲染路径中已确认的字体并发竞争随功能删除而消除。
- 已移除或不存在的 `/api` 路径返回 404，不再回退为前端 HTML 页面。原先嵌入 MJPEG 地址的外部页面需要移除相应图片引用。

本版只更新服务端。内嵌前端继续固定在 1.2.8 对应提交，Agent 继续使用 1.2.8，无需同步升级。节点上报、状态页面、监控图表、延迟检测、DDNS、管理后台及终端继续沿用现有实现。

无需数据库迁移；不修改节点、登录、2FA 或 DDNS 配置，也不自动删除数据目录中可能存在的旧字体文件。

验证包括已移除接口及未知 API 的 404 回归、现有接口可用性、完整 Go 短测试、发布流程要求的竞态检查、漏洞扫描与跨平台构建。备份恢复内容校验及原子替换问题不在本次变更范围内。
