# 1.2.7 安全修复说明

本版根据 2026-09-25 安全审计的源码复核修复业务授权、凭据暴露与资源限制问题。保留终端、DDNS、GitHub 登录、内网监控及单 SQLite 数据库；不把管理员主动执行脚本或安装主题等能力误报为未授权漏洞。

## 服务端

- 旧版 POST 上报绑定认证节点 UUID，跨节点 UUID 返回 403；v1/v2 基础信息仅允许硬件、系统、地址和版本字段，不能改 token、名称、隐藏状态、分组、账单等管理字段。
- 终端 Agent 回连绑定目标节点；同步会话生命周期及写入，处理空帧和断连清理。浏览器先经敏感操作验证领取 30 秒、一次性、绑定用户及节点的票据，再连接 WebSocket；OTP 不再放入 URL。
- 密码登录仅通过 HttpOnly Cookie 设置会话，JSON 不回显凭据；会话管理返回 SHA-256 标识，注销使用该标识，标识不能用于认证。统一检查会话到期。
- REST/RPC 历史查询最多 366 天、单次合计 200,000 行、最多 4 个并行请求；数据库查询 30 秒超时。超过限制明确失败，需缩短时间或指定节点，避免返回看似完整的截断统计。
- 分享链接先换取 HttpOnly / SameSite Cookie（HTTPS 使用 Secure）并去除 URL 中的凭据，再加载页面。增加 no-referrer、禁止跨站嵌入和基础 CSP；自定义主题/管理员 HTML 仍属于受信任代码，未宣称彻底隔离。
- 下载主题时在实际拨号环节校验所有解析地址，固定拨号到校验过的地址，重定向不能绕过内网检查或使 HTTPS 降级。该下载器不使用环境 HTTP 代理。
- Generic/QQ OAuth state 有界且只消费一次，QQ 回调地址带 state 并强制与 Cookie 匹配；请求有超时。GitHub 原有路径保留。
- `chpasswd --password-stdin` 支持从标准输入读取密码，成功消息不输出密码。敏感密钥使用恒定时间摘要比较。
- JavaScript 通知按单个 VM 串行执行，30 秒截止时间能中断脚本循环；HTTP 与回调由 VM 所在执行线程处理，响应最多 4 MiB，定时器最多 128 个，每次发送最多 256 次定时器/HTTP 操作。忙碌时返回错误而非无限排队。这是资源保护，**不是不可信 JavaScript 的完整内存/进程沙箱**。

## 前端与 Agent

前端移除输入框的 Function 执行，保留数字、乘法、科学计数法与单位输入；页脚 HTML 使用 DOMPurify 净化；raw iframe 不再同时获得脚本与同源权限；移除长期 API 缓存及敏感调试输出。更新依赖并在构建流程加入 npm audit。

Agent 远程命令最多并行 4 个、每个 10 分钟、每个输出流 64 KiB；超时清理进程树。终端最多 4 个，探测最多 64 个并行。日志不记录完整命令。控制通道拒绝跨来源重定向；公网地址探测使用 HTTPS，流量状态文件权限收紧。私网探测不禁用。

新安装器通过校验后的 Agent 把配置写入仅所有者可读的文件（Windows 使用 ACL），服务启动参数只引用配置文件；输入不再拼进服务定义。代理仅分发二进制，校验值从 GitHub 直接获取；无法直连校验值时安装失败。Windows NSSM 2.24 下载使用固定 SHA-256。

## 升级注意

- 服务端必须使用与本版前端匹配的构建，旧页面需刷新以使用新的终端票据接口。
- raw iframe 不再能操作父页面；页脚中的脚本、事件属性、样式及表单会被移除。可执行定制仍只能通过受信任的主题/管理员设置管理。
- JavaScript 通知的 HTTP 调用串行执行；异步通知脚本应返回/等待自己的 Promise。不得依赖发送函数返回后继续运行的后台 goroutine。
- 反代默认仅信任回环及私有网段。公网反代需通过 `KOMARI_TRUSTED_PROXIES` 设置明确的 IP/CIDR，逗号分隔；空值表示不信任任何代理。代理必须覆盖外部传入的转发头。
- QQ 聚合提供商必须保留回调地址中的 state；不保留时登录安全失败。用户当前使用的 GitHub 登录不受此项影响。
- **仅替换现有 Agent 二进制不会改写旧服务的 token 启动参数。** 要迁移到私有配置，需重新运行本版安装器或手动更新服务定义。配置导出要求 Agent 1.2.7 及以上；安装旧版本请使用对应版本安装器。
- root/SYSTEM 运行、显式 HTTP/忽略证书选项、管理员 API Key 的高权限、管理员主题/脚本信任边界保留。独立发布签名信任根及进程级脚本沙箱不在本次补丁范围内，不能声称所有设计风险已消除。

## 回归验证

新增节点越权、终端身份/双向转发/空帧/一次性票据、会话过期及注销标识、下载目标策略、OAuth state 并发重放、查询范围/并发、代理头信任、JS 定时器及执行中断、前端表达式/页脚注入、Agent 超时与输出/并发等回归测试。CI 和发布执行完整短测试、重点 race 测试、依赖扫描、前端构建及平台构建；Agent 发布额外要求 Windows 测试和安装器语法检查通过。
